New: Template Preview v2. Save multiple named context profiles per template (or a workspace-wide `*` fallback) in your settings, switch between them from a sidebar, and start fast with built-in mock data presets (`user`, `list`, `paginated`, `form`). The rendered preview now updates live as you edit the JSON context or the template itself, missing variables show as clickable chips that you can add to the active profile with one click, and the context editor can be collapsed to give the rendered preview the full panel width. Adds the `Jinja2: Preview Template with Profile` quick-pick command.
